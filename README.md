# 我常用的脚本插件

收录我常用的脚本和插件配置。

## 知乎设置

油猴脚本，用于知乎深色/浅色主题切换和移除 AI 总结卡片。

## 功能

- 通过油猴菜单一键切换深色/浅色主题（默认深色）
- 多色彩主题预设：默认深色、深青绿、纸张浅色（浅色模式专用）
- 修复知乎原生深色模式下少量组件遗漏
- 移除 AI 总结卡片

## 安装

[点击安装 zhihu-config.user.js](https://raw.githubusercontent.com/sfw222/my-scripts-and-plugins/main/zhihu-config.user.js)

## 使用

点击油猴图标 → 脚本菜单 → 选择「深色模式」或「浅色模式」。

## 流畅阅读 · 油管字幕放到视频下方

将流畅阅读的双语字幕显示在 YouTube 视频下方，支持普通模式和影院模式，全屏时恢复视频内字幕。字幕颜色、字号和双语顺序跟随流畅阅读设置。

[点击安装 fluent-read-youtube-subtitles.user.js](https://raw.githubusercontent.com/sfw222/my-scripts-and-plugins/main/fluent-read-youtube-subtitles.user.js)

安装后，停用旧的字幕下移脚本，刷新 YouTube，并开启流畅阅读的视频字幕翻译。在油猴脚本菜单中可切换「字幕下移」和「点击英文单词查词」。查词默认关闭，开启后点击原文中的英文单词可打开剑桥词典，成功打开词典窗口后暂停视频。
